# MambaEnhancedFarGan 项目｜长记忆说明文档（问题归档与修复路线）

> 本文作为“长记忆”记录，持续汇总当前模型与训练中暴露的问题、诊断结论、已做/待做改动，以及可复现实验与监控指标，便于后续持续迭代与对比。

---

## 0. 背景与目标

* 任务：端到端语音重建（16 kHz），以 FarGAN/FARGAN 思想为参考，将 **Mamba/GSSM** 融入条件与子帧网络，支持并行训练（Teacher Forcing）与后续对抗精修。
* 近期目标：**先把预训练阶段稳定到可用音质**（消除“电流音/机械噪声”），再在此基础上引入判别器对抗训练做细节提升。

---

## 1. 主要症状（从评估与主观听感汇总）

1. **电流音/机械噪声**

   * 预训练与 polish 后均存在，GAN 前已经能听到。
   * STFT 指标不算极差，但**瞬态/相位局部不稳**，听感受损严重。

2. **时间对齐偏移**

   * `eval_fargan.py` 报告的 `diag lag ≈ 24–48 ms`。
   * 需要使用互相关对齐才能得到略好指标，说明**生成端相位/时延漂移**。

3. **振幅塌缩/动态范围不足**

   * 多次评估中 `pred_range` 明显低于 `target_range`（甚至 ±0.07～0.11），**能量明显不足**。
   * 训练中增益策略偏保守，且**缺少与能量特征强绑定的振幅控制**。

4. **训练时长增长，但听感无显著改善**

   * Polish（阶段 B）增加了时长与复杂度，对抗/教师强制切换等尝试，**收益有限**。

---

## 2. 根因分析（结构 × 数据 × 训练）

### 2.1 架构层面

* **缺少 FARGAN 的“激励记忆（excitation memory）+ 周期索引取样 + 写回”闭环**

  * 原版核心：维护 256 样本 `exc_mem`，每子帧通过**周期索引**从 `exc_mem`取一段 `pred` 作为**pitch excitation**，再与 `prev`、`cond`一同生成当前子帧并**写回 exc\_mem**。
  * 现状：`_simple_pitch_prediction` 只是“上一子帧复制/片段回放”，**没有真正的“按周期索引取样”**与“滑动记忆写回”，导致**周期一致性差、相位不稳** → 电流音的常见源头。

* **增益路径不等价**

  * 原版：`gain = exp( cond_gain_dense(cond) )`，并对 **pred/prev/sig** 全路径做轻噪声/软限幅，稳幅且抑制尖峰。
  * 现状：采用 `1 + 0.5 * tanh()` 限幅增益（稳但**抑制动态范围**）；且**与能量特征的强绑定缺失**，难以在不同样本上学好振幅标定。

* **条件输出与子帧“硬结构”不一致**

  * 原版：每帧输出 **4×80** 的“子帧块”，子网严格以 `k*80:(k+1)*80`切片。
  * 现状：Mamba 条件端输出 96 维“连续特征”，**未刻意对齐到“80 维子帧块”的硬切片结构**，导致子帧网络在“读条件”的语义上不够确定。

### 2.2 数据/对齐

* **训练裁剪与对齐策略**

  * 原版：严格将 `target` 裁到 `sequence_length*160`，`features/periods` 到 `sequence_length+4`；训练 loop 内按帧/子帧索引**精准对齐**。
  * 现状：虽也裁剪，但**预热帧 nb\_pre=2 未贯彻到“先预热再自回归”的过程**，Teacher Forcing 多为整段并行，损失对时间偏移的惩罚不强，**漂移不易收敛**。

### 2.3 训练目标与损失

* **缺少短窗“单位能量余弦距离”`sig_loss`**

  * 原版：预训期 `loss = MR-STFT + 0.03 * sig_loss(80 样本窗)`，抓瞬态与相位局部一致性；
  * 现状：仅 MR-STFT（加上可选 phase loss），**对短窗相位/瞬态约束不够**，更易出现“嗡嗡/电流”类噪声。

* **对抗时序与冻结策略**（polish 阶段仍薄弱）

  * 原版：先只训判别器若干 step，再解冻生成器但**冻结 cond\_net / cond\_gain\_dense**，让判别器提供稳定信号；
  * 现状：polish 尝试过开/关教师强制，但**未引入 FM loss + 判别器**稳定过程，因而 polish 收益有限。

### 2.4 优化器/调度与稳定化

* 预训成功范式通常用 **AdamW(betas=(0.8,0.95)) + 简单衰减**，并多处引入**轻噪和软限幅**；
* 现状：引入了 **anti-clip/DC/RMS/EMA/warmup+cosine** 等优化，但**在上层结构未对齐的前提下，收益被掩盖**，听感仍受限。

---

## 3. 已尝试与结论

* ✅ **损失侧**：MR-STFT、（可选）phase loss、通道自适应，已跑通；
* ✅ **稳定化**：DC 去除、RMS 归一、anti-clip、EMA、warmup+cosine，训练曲线更稳；
* ❌ **听感仍存在电流音**：说明问题更多在**生成闭环结构/增益路径/短窗约束**。
* ✅ **DDP/AMP/compile/冻结**：流程和资源利用基本 OK；
* ⚠️ **Teacher Forcing**：“整段并行”没有替代“预热 + 自回归”的效果。

---

## 4. 与原版 FARGAN 的关键差异（必须对齐的点）

1. **激励记忆 `exc_mem(256)` + 周期索引取样 + 写回滑窗**（最关键）
2. **nb\_pre=2 预热帧**：先用真值填充 `exc_mem`，再开始自回归生成
3. **短窗 `sig_loss(80)`**：预训期就要上，权重 \~0.03
4. **增益路径**：`gain = exp(cond_gain_dense(cond))` 或与**能量特征**强绑定的等价映射，并对 `pred/prev/sig`做**轻噪/软限幅**
5. **条件输出“子帧块化”**：确保 cond 对齐 `k*80:(k+1)*80` 的**硬切片**习惯
6. **对抗阶段策略**（后续）：先训判别器、生成器解冻时**冻结 cond\_net/cond\_gain\_dense**；加入 FM loss

## 5. 近期修复路线（优先级从高到低）

* [ ] **P0**：在 `MambaEnhancedFarGan.forward` 引入 **`exc_mem` 闭环**

  * 初始化 `exc_mem=[B,256]`、`prev=[B,40]`
  * **按周期索引**从 `exc_mem`取 `pred`，与 `prev/cond/gain` 一起过子网
  * 输出 `sf` **写回** `exc_mem`（滑窗拼接），`prev ← sf`
* [ ] **P0**：实现 **nb\_pre=2 预热帧**（用真值写入 `exc_mem` 后再开始自回归）
* [ ] **P0**：加入 **短窗余弦损失 `sig_loss(80)`** 并在预训阶段使用（MR-STFT + 0.03\*sig\_loss）
* [ ] **P1**：**增益路径**改为与能量特征强绑定（可模仿 FARGAN 映射公式），并用 gain 归一/反归一 `pred/prev/sig`
* [ ] **P1**：为子帧网输入加 **轻噪声 + 软限幅 `n(x)`**（关键节点 2–3 处即可）
* [ ] **P2**：条件输出对齐**80 维子帧块**（可将 96→80 或前 80 留给主干）
* [ ] **P2**：优化器先回到 **AdamW(lr∈\[5e-4,1e-3], betas=(0.8,0.95))**，调度可先停或用简单衰减
* [ ] **P3**（预训稳定后）：引入 **FDMResDisc + FM loss + GAN**，并采用\*\*先训判别器→解冻生成器（冻结 cond 分支）\*\*的节奏

---

## 6. 可复现实验设计（建议顺序）

1. **Baseline-A（结构修复）**

   * 只引入 `exc_mem + 周期索引 + 写回 + nb_pre=2`，其他不变；
   * loss = MR-STFT；优化器 AdamW(0.0005, betas=(0.8,0.95))；
   * 指标：听感（是否消除电流音）、`pred_range` 提升、对齐 lag 缩小。

2. **Baseline-B（加短窗损失）**

   * 在 A 的基础上，loss = MR-STFT + 0.03 \* sig\_loss(80)；
   * 指标：短音瞬态、啸叫/噪声进一步收敛。

3. **Baseline-C（增益路径绑定 & 轻噪声/软限幅）**

   * 引入 gain=exp(cond\_gain\_dense(cond)) 或能量公式映射；在 `pred/prev/sig` 上做 `n(x)`；
   * 指标：`pred_range` 更接近 `target_range`，响度稳定，无破音。

4. **Adv-Stage（对抗）**

   * 判别器 FDMResDisc；先训判别器 400 step；解冻生成器但冻结 cond/cond\_gain；
   * loss\_gen = reg\_loss(MR-STFT+sig\_loss) + FM + GAN；
   * 指标：细节/清晰度提升，无新噪声引入。

---

## 7. 训练监控与验收门槛

* **波形统计**：`pred_rms/tgt_rms` 接近（0.8\~1.2 范围）、`pred_dc≈0`、`clip_rate<0.5%`
* **对齐**：`diag lag` 收敛到 **< 10 ms**（越小越好）
* **短窗余弦相似度**：`sig_loss(80)` 稳定下降
* **主观听感**：无明显电流音/啸叫，语音基频与共振峰可辨，停顿/爆破音不毛刺
* **评估样本**：固定 8/16 条样本列表，使用同一 `--seq-len` 与裁剪方式，避免漂移

---

## 8. 常见坑与规避

* **DDP 报“unused params”**：未用分支需在 **DDP 前冻结**；或 `find_unused_parameters=True`（但慢）。
* **Teacher Forcing 整段并行 ≠ 自回归**：要**预热后自回归**，否则时延/相位难对齐。
* **增益过度限幅**：`1+0.5*tanh` 太保守会**压动态**，优先上“能量映射 + exp”。
* **MR-STFT 只看频谱**：不加短窗时域约束容易有“电流音”。
* **评估对齐**：必须做互相关对齐后再看指标，否则被时延误导。

## 9. 决策记录（简要）

* ✅ 采用 Mamba/GSSM 作为条件建模主干 —— 保留
* ✅ 训练脚本已加入 DC/RMS/anti-clip/EMA/warmup+cosine —— **在结构修复前可暂时简化调度**
* ❌ polish 阶段单靠长时训练与教师强制，**无法根治电流音** —— 需回到结构与损失
* ⏳ 下一步：按“修复路线”先做 **P0/P1**（结构闭环 + 短窗损失 + 增益绑定）

### 附：推荐的最小代码修改点（概述）

> 以下为“改哪里”的指引（具体代码已在过往消息分批给出/讨论）：

* 顶层 `MambaEnhancedFarGan.forward`：

  * 新增 `exc_mem` 初始化与维护；
  * 在子帧循环体内：

    1. 由 `period` 计算索引并从 `exc_mem`取 `pred`；
    2. 调用子帧网，输出 `sf`；
    3. `exc_mem = concat(exc_mem[:,40:], sf)` 写回；`prev = sf.detach()`；
  * 在进入循环前，对 `teacher_signal` 做 **nb\_pre=2** 的预热写入。

* `CSIAwareSubframeNet.forward`：

  * 输入端增加 `pred/prev/cond` 拼接前的 **gain 归一**，输出端乘回 **gain**；
  * 关键处插入 `n(x)`（轻噪声 + clamp/tanh）以抑制尖峰。

* 训练脚本：

  * 在计算 loss 前抽取 **短窗 80 样本**做 `sig_loss`（单位能量余弦距离），`loss = mrstft + 0.03*sig_loss`；
  * 监控：`pred_rms/tgt_rms`、`clip_rate`、`lag`、`sig_loss` 曲线。

**结论**：
当前音质问题的根源不在“训练时长”或“是否开启教师强制”，而在于**生成闭环（激励记忆+周期索引）与短窗时域约束**这两件“让模型会说话”的关键。先把 **P0/P1** 做扎实（按 FARGAN 的那套思路），你的 Mamba 条件主干反而会成为优势：**全局稳态由 GSSM 提供，局部瞬态由子帧闭环固化**。当预训练声音“干净且稳”以后，再上判别器做精修，才是事半功倍的节奏。
